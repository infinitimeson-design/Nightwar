# 🇬🇧 English

## ✦ Overview

**SCdev** is a personal web design portfolio created to showcase my approach to modern interface design, frontend development, responsive layouts, and creative digital experiences.

The visual identity combines a **developer terminal aesthetic** with a clean and modern portfolio structure, turning technical elements such as commands, code blocks, and system-style UI into part of the overall design language.

The project is designed to present both **technical skills** and **visual creativity** in one interactive experience.

---

## ✦ Highlights

* 🖥️ Terminal-inspired visual identity
* 🎨 Modern UI / Web Design
* 📱 Responsive layout
* ⚡ Lightweight frontend architecture
* 🧩 Interactive navigation and UI elements
* 💻 Developer-focused visual language
* 🗂️ Dedicated project showcase
* 📬 Contact section
* 🌐 Static deployment with GitHub Pages

## ✦ Design Direction

The project follows a deliberately technical visual language:

```text
DESIGN
  ↓
Terminal UI
  +
Developer Aesthetic
  +
Modern Web Design
  +
Responsive Experience
```

Instead of using the developer aesthetic purely as decoration, the interface uses **code, commands, file structures, and terminal patterns as part of the UI itself.**

---

## ✦ Project Goals

The main goals of this project are:

* Build a recognizable personal digital identity
* Showcase web design and frontend skills
* Experiment with unconventional portfolio layouts
* Practice responsive web development
* Create a portfolio that feels like a designed product rather than a traditional resume

# 🇮🇷 فارسی

## ✦ معرفی

**SCdev** یک پورتفولیوی شخصی در حوزه طراحی و توسعه وب است که با هدف نمایش مهارت‌ها، پروژه‌ها و رویکرد من در زمینه طراحی رابط کاربری، توسعه Frontend، طراحی واکنش‌گرا و ساخت تجربه‌های دیجیتال خلاقانه ایجاد شده است.

هویت بصری پروژه ترکیبی از **فضای ترمینال و دنیای توسعه‌دهندگان** با یک ساختار مدرن و مینیمال پورتفولیو است.

در این پروژه، المان‌هایی مانند دستورات ترمینال، ساختار فایل‌ها، کد و رابط‌های سیستم‌محور صرفاً جنبه تزئینی ندارند؛ بلکه بخشی از زبان طراحی رابط کاربری هستند.

هدف این است که **مهارت فنی و خلاقیت بصری** در قالب یک تجربه تعاملی و یکپارچه نمایش داده شوند.
