## 🇬🇧 English

### Overview

**Sicily Cut** is the official landing page for Sicily Cut Barber Studio — a minimal, fast-loading one-page site designed with a dark, contemporary Italian aesthetic. Built with zero dependencies and zero build steps, it loads instantly and works everywhere.

No frameworks. No bundlers. No bloat — just clean HTML, CSS, and JavaScript.

### Tech Stack

| Layer | Technology |
|---|---|
| Markup | HTML5 |
| Styling | CSS3 (custom properties, glassmorphism, responsive grid) |
| Behavior | Vanilla JavaScript (ES6) |
| Fonts | [Cinzel](https://fonts.google.com/specimen/Cinzel) + [Inter](https://fonts.google.com/specimen/Inter) via Google Fonts |

### Features

- 🎬 Animated splash screen with logo intro
- ✨ Luxury glassmorphism UI (blurred glass cards & buttons)
- 📜 Scroll-reveal animations via `IntersectionObserver`
- 💫 Ripple effect on interactive buttons
- 🖱️ Parallax hero logo on scroll
- 📍 One-tap location, call, WhatsApp & Telegram shortcuts
- 📱 Mobile-first, fully responsive (320px → 1440px+)
- ♿ Accessible: semantic markup, focus states, `prefers-reduced-motion` support
- ⚡ Optimized performance — no external JS libraries

### Design System

**Colors**

| Token | Value | Usage |
|---|---|---|
| Background | `#0B0B0B` | Base background |
| Emerald | `#0F5C4D` | Primary accent |
| Emerald Soft | `#8FD3C3` | Highlights & prices |
| Text | `#F5F5F5` | Primary text |
| Text Secondary | `#B9B9B9` | Muted / secondary text |

**Typography**

- **Cinzel** — headings, wordmark, luxury serif accents
- **Inter** — body copy, UI labels

### Getting Started

No build step required.

```bash
git clone <repo-url>
cd Sicily-cut
```

Then simply open `index.html` in a browser, or serve it locally:

```bash
npx serve .
```
